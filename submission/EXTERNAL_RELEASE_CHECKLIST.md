# External Release Checklist

Every item below is an uncompleted human action. Nothing in this checklist asserts that an
external release, deployment, upload, or submission has occurred.

1. [ ] Optional but strongly recommended bounded live GPT-5.6 smoke on stable_symmetric.
2. [ ] Run `/feedback` in the principal Codex build thread and copy the Session ID.
3. [ ] Create or verify the GitHub repository.
4. [ ] Push branch `build-week-2026` and annotated submission tag.
5. [ ] Make the repository public with license, or configure official judge access.
6. [ ] Verify the public repository and README while logged out.
7. [ ] Deploy Streamlit from:
   - branch `build-week-2026`;
   - entry point `streamlit_app.py`;
   - Python 3.12.
8. [ ] Verify all three deployed scenarios.
9. [ ] Record the video from the final script and shot list.
10. [ ] Upload publicly to YouTube.
11. [ ] Confirm duration at or below three minutes, audible English narration, working project,
    Codex role, GPT-5.6 role, no secrets/private data, and no unlicensed material.
12. [ ] Complete Devpost:
    - Work & Productivity;
    - description;
    - repository URL;
    - demo URL;
    - public YouTube URL;
    - `/feedback` Session ID.
13. [ ] Submit before the official deadline.
14. [ ] Open the submitted page and verify every link.
15. [ ] Save confirmation screenshots locally.
